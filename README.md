🚀 Smart Hiring Prediction System using Machine Learning
dataset link https://www.kaggle.com/datasets/roiiith/ai-fair-recrutment-dataset/data

📌 Project Overview
This project builds a machine learning-based hiring prediction system that helps recruiters make data-driven decisions. The model predicts whether a candidate will be hired based on features such as Interview Score, Total Skill Score, Education Level, Experience Level, Certifications, and Job Role.

A trained model is deployed using Flask with an interactive web interface for real-time prediction.

🎯 Objective
The objective of this project is to:

Predict hiring decisions accurately.
Analyze how Interview Score, Skill Score, and Education Level affect recruitment.
Provide a fair, consistent, and data-driven hiring support tool.
